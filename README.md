# Kingdomlympics

A youth church competition event by **NextGen DUMC** — four battle games leading up to a Grand Finale showdown. Teams compete across age groups (13–17) in a series of challenges across the year.

## Event Details

- **Date:** 23rd August 2026
- **Time:** 3:00 PM – 9:00 PM
- **Location:** DUMC Dream Centre
- **Who:** 13–17 years old
- **Sign Up:** https://tinyurl.com/KO26FINALE

## Tech Stack

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS v4
- **Animation:** Framer Motion (`motion`)
- **Icons:** Iconify (`pixelarticons` set)

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the dev server:
   `npm run dev`
